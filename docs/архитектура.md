# Архитектура системы управления задачами команды

## Уровень C1 (Контекстная диаграмма)
**Описание:** Система предназначена для организации рабочего процесса команды. 
**Пользователи:**
* **Сотрудник:** Создает задачи, обновляет их статус, оставляет комментарии.
* **Менеджер:** Назначает задачи, контролирует дедлайны, формирует отчеты.

**Внешние системы:**
* **Сервис уведомлений:** Отправляет оповещения о новых задачах и дедлайнах.
* **Система авторизации:** Вход через корпоративные аккаунты.

## Уровень C2 (Диаграмма контейнеров)
**Описание:** Внутреннее устройство системы.

1. **Веб-приложение:** Интерфейс для пользователей (браузер). Отвечает за отображение досок задач, форм создания задач и профилей.
2. **API Сервер:** Обрабатывает бизнес-логику, права доступа и запросы от Frontend. (Технологии: Python/Node.js/Java).
3. **База данных:** Хранит информацию о пользователях, задачах, проектах и комментариях. (Технологии: PostgreSQL).
4. **Сервис фоновых задач:** Отвечает за рассылку уведомлений и проверку дедлайнов.
