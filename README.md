# Система управления задачами команды

## Описание проекта
Веб-приложение для эффективного планирования и отслеживания задач внутри команды. Система позволяет создавать проекты, назначать исполнителей, устанавливать дедлайны, отслеживать прогресс (Kanban-доска) и получать уведомления о предстоящих сроках. 

## Технологический стек
* **Язык:** Python.
* **Backend:** Node.js.
* **База данных:** PostgreSQL.
* **Инфраструктура:** Docker, GitHub Actions (CI/CD)
